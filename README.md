# Path to Red Hat Certified Architect (RHCA)

These are my personal study notes for the path to Red Hat Certified Architect
in Enterprise Linux (RHCA). My notes are based on publically available Red Hat
exam objectives; no exam content is disclosed. I studied using third party
materials with no access to RHLS, and I feel that I've learned many invaluable
things about the internals of Linux while studying for these exams. It's
satisfying and validating to complete a difficult exam!

If you are a Red Hat employee and something about this repository is not allowed,
please send your comments to [mail@lianas.org](mailto:mail@lianas.org) and I will
make any changes required.
