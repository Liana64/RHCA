# Path to Red Hat Certified Architect (RHCA)

I've enjoyed this certification path so far, it feels satisfying and validating to complete a difficult exam! I like that Red Hat exams are practical, focused on solving real problems, and do not include access to the internet.

I've learned many invaluable things about the internals of Linux while studying for these problems, and I've studied using courses available on O'Reilly with no access to RHLS. Anki cards generated via Claude decomposition of my own notes.
