**Remember**
- If writing disks, remember to set a disk type
- Booting from `systemd.unit=emergency.target`
- `grubby --update-kernel=ALL --args="crashkernel=auto"` for core dumps
- Put SystemTap modules in `/lib/modules/$(uname -r)/systemtap/`
- Remember `audit2why` and `setroubleshoot`
- Use `strace`, it can help find errors
- Use `find /` and `rpm -Va`
- Persistent logs
    - `Storage=persistent` goes to `/etc/systemd/journald.conf`
    - `mkdir -p /var/log/journal` and `chown root:systemd-journal /var/log/journal`
    - `chmod 2755 /var/log/journal` and `killall -USR1 systemd-journald` to restart
- PAM
    - `tail -f /var/log/secure`
- Kerberos
    - principal: `host/fqdn@REALM` (`man kerberos`)
    - `systemctl status {nscd,nslcd,sssd,chronyd}`
    - `su - <user>` change to affected user
    - `kinit <user>` creates a ticket
    - `exit`
    - `klist -ek` to verify the keytab and get password version
    - `kadmin getprinc some_principal` must match password version 
    - `systemctl status ipa-server` (server)
    - `systemctl status krb5-workstation`
- LDAP
    - `chown root:root /etc/sssd/sssd.conf` must be owned by root
    - `chmod 600 /etc/sssd/sssd.conf` must be `600`
    - `ipa-client-install --mkhomedir` to setup an IPA client if needed
    - `cacertdir_rehash /etc/openldap/cacerts` to sign the CA cert
- Libraries
    - `find / -name 'lib<something>.so*` to check path of library
    - `ldconfig -p` to print linker cache and `ldconfig` to rebuild
- Encryption
    - `cryptsetup luksDump /dev/device` to dump headers
    - `cryptsetup luksOpen /dev/device name` to open a device
    - `mount /dev/mapper/name /mnt` to mount device
    - `cryptsetup luksAddKey /dev/device` to add a new key
    - `cryptsetup luksHeaderBackup /dev/device --header-backup-file /root/backup`
    - `cryptsetup luksHeaderRestore /dev/device --header-backup-file /root/backup`
- `man 5 rsyslog.conf`
- iSCSI (step 1)
    - IQN format must be `iqn.<YEAR>-<MONTH>.<TLD>.<DDOMAIN>:<NAME>`
        - e.g., `iqn.2026-04.com.example:san`
    - Use the `_netdev` disk option in fstab for iSCSI devices
    - Target is the storage server exporting disk(s)
    - Initiator is the iSCSI client 
    - Anything after the `:` is just the name or hostname, identify the device
    - On the client, edit `/etc/iscsi/initiatorname.iscsi` and add:
        - (for example) `InitiatorName=iqn.2026-04.com.example:client`
        - identifying that device
    - On the server, create an ACL with the client's IQN defined in
    - `/etc/iscsi/initiatorname.iscsi`, using `targetcli` like below:
    - `/iscsi/iqn.20...ost/tpg1/acls> create iqn.2026-04.com.example:client`
    - Restart the `iscsid` service if any names change
    - in `targetcli`, don't forget to use `exit` to save changes!!
    - Make sure the iSCSI port is open for portals
    - `systemctl enable --now target` is required on the server
    - `systemctl enable --now {iscsi,iscsid}` is required on the client
- iSCSI (step 2)
    - `iscsiadm -m discoverydb -t st -p <Server_IP> --discover`
    - `iscsiadm -m node -T iqn.2026-04.com.example:target-host -p <Server_IP>`
    - Write filesystem, etc.
    - In fstab, `UUID=<uuid> /mnt xfs defaults,_netdev 0 0` (`_netdev` required)

#### Systemd

**Systemd Dependency Types**

- `Requires=` starts the specified unit(s) when started
- `RequiresOverridable=` allows the required unit(s) to fail if run by an administrator
- `Requisite=` requires that the specified unit(s) are already running or will fail
- `Wants=` requests that the specified unit(s) are already running, but will not fail
- `Conflicts=` will stop all specified units if run
- `Before=` specifies that it will be loaded before the specified unit(s)
- `After=` specifies that it will be loaded after the specified unit(s)

**Boot from grub menu**

1. Press "e" to edit
2. Navigate to "linux"
3. Add one of the following:
    - `rd.break` (Break before root is mounted)
    - `systemd.unit=rescue.target` (Single user with local FS mounted)
    - `systemd.unit=emergency.target` (Minimal with root FS mounted read only)
    - `init=/bin/bash` (Bypass systemd)
4. Press Ctrl+X to boot
5. If no root (`rd.break`), use:
    - `mount -o remount,rw /sysroot`
    - `chroot /sysroot`
6. To remount root with write perms, use:
    - `mount -o remount,rw /`
8. Change root password using `passwd` if desired
9. To trigger relabeling on next boot:
    - `touch /.autorelabel`, or:
    - `restorecon -v /somefile`
10. To start systemd manually:
    - `exec /usr/lib/systemd/systemd`
    - or, `exit`

**Recovering lost partitions**

When deleting partition(s) using fdisk, only the partition table in the MBR is updated, so no data is actually lost (just the index). Use fdisk to create partitions as needed, discovering the size (end) of each as you go. If you have another machine, it may help to investigate the start and end of partitions there. Reference the GPT table or protective MBR at the end of the disk if needed.
