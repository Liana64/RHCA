# Red Hat Certified System Administrator (EX200)

**Plan**

- Start with `mandb`
- Use `man -k something && man -Kw somekeyword`
- Read all questions and do partitions first
- Count tasks and divide by time left
- Step 1 -> Setup
  - `mandb`
  - `visudo` if needed
  - `cat >> ~/.bashrc <<EOF export EDITOR=vim, etc. EOF`
- Step 2 -> SSH public key auth
  - `ssh-keygen`
  - `ssh-copy-id -i key.pub host`
- Step 3 -> Repos
- Check everything once done

- `grubby --update-kernel=ALL --remove-args="rhgb quiet"` OR

**Tips**

- Use your mouse to copy and paste
- We will be expected to manually configure repositories
- Reboot after major changes, it's easier to troubleshoot when you know what you were doing
- Use `apropos` and `man` and use them a lot
  - Use `mandb` on first boot to build the man db
- ==Make sure that the system reboots successfully before exiting the exam==
  - If you leave a machine with a broken fstab, the entire machine will not be graded and you will fail the exam

**Practice**

- Containers
  - `ssh user@localhost`
  - `mkdir -p ~/.config/systemd/user`
  - `loginctl enable-linger some_user`
  - `podman unshare chown user:group folder`
  - `...`
  - `podman generate systemd --new --files --name some_container`
  - `systemctl --user daemon-reload`
  - `systemctl --user enable --now containerfile`
- Setting up repos (yum!)
  - `dnf repolist`
  - `dnf group list`
  - Remember to use `dnf provides */Some_file`
  - `dnf update kernel` add new kernel and backup old
- Rpm
  - `rpm -qa` to view installed packages
- Shared folders and sticky bits
  - `chmod g+s` to share or `chmod 2770`
  - `chmod +t` for sticky bits or `chmod 5770`
- Tuning profiles
  - `tuned-adm`
- Fs
  - `wipefs -a /dev/sdf` to wipe a fs
  - `resize2fs` to resize a fs if you forgot `-r` on `lvextend`
- Processes
  - `nice -n 19 sleep 600 &`
    - Set process priority and send to bg
- Process scheduling
  - View `/etc/crontab`
- Grep
  - `grep -i` case insensitive
- Logrotate
- Date
  - `timedatectl`
- Autofs
- Systemctl
  - `systemctl get-default` and `systemctl set-default multi-user.target` (or `graphical.target`) to set default target
  - `systemctl show some.unit` to show all vars
  - `systemctl edit --force --full some.unit` to edit a unit
- Modify grub config
  - `grubby --update-kernel=ALL --remove-args="rhgb quiet"`
- Targets (Grub menu)
  - `systemd.unit=emergency.target`
  - `systemd.unit=rescue.target`
- Bash
  - `if [ $test ]; then echo hello; fi;`
  - `while $i; do echo hello; done;`
  - `for i in $test; do echo $i; done;`
- Networking
  - `nmtui
- SELinux
  - `restorecon -Rv /somedir`
  - `setsebool -P somebool on` for persistence!
- Users
  - `id username`
  - Modify id `usermod -u 1234 username`
  - Use `chage` to set expiration date for password
- Root password reset
  - `init=/bin/bash && mount -o remount,rw / && passwd && touch /.autorelabel`

**Boot Procedure**

Firmware -> Boot Device -> Boot Sector -> Boot Loader (Grub) -> Linux Kernel -> initramfs/initrd helper -> Systemd -> Early states -> Services -> Shell is dropped

**Misc commands to remember**

- `apropos mkfs` (example)
  - Search for commands
  - Most important thing to remember
- `mandb`
  - Build man database (required on first boot)
  - Second most important thing to remember
- `visudo`
  - Use only this to edit sudoers!
- `nmtui`
  - Network management TUI
- `ss -tunap`
  - View processes with sockets open
- `ps fax`
  - View process tree
- `cp /etc/[acf]* /myfiles`
  - Copy files starting with a, c, or f to `/myfiles`
- `mkdir /tmp/folder{1..10}`
  - Make folder1, folder2, folder3, folder4, etc., until folder10
- `find / -name journald.conf 2> /dev/null`
  - Search for file names and block STDERR
- `nice -n 19 sleep 600 &`
  - Set process priority and send to bg
- `jobs && fg 1`
  - List jobs, and;
  - Bring job 1 to the fg
- `grep -i '^UUID' /etc/fstab`
  - Search for strings starting with UUID in fstab
  - Remember that you can use vim chars here!
- `watch somecommand`
  - Runs a command every 2 seconds, live
- `findmnt && lsof`
  - List all mounts with nested info, and;
  - Lists all open files
- `lsblk && blkid`
  - List all block devices, and;
  - List all block device identifiers
- `journalctl -u sshd.service -f -o verbose`
  - Follow verbose output for systemd unit sshd.service
  - Uses systemd-journald
- `blkid | grep sda2 | awk '{ print $2 }'`
  - Selects sda2 and uses awk to print the second slice of the line
- `blkid | awk '/sda5/ { print $2 }`
  - Uses awk to find sda5 and prints the second slice of the line
- `mkswap /dev/sda7 && swapon && free -m`
  - Create swap FS on block device sda6, and;
  - Enable swap (equivalent to `mount -a`), and;
  - View free memory (including swap)
  - NOTE: Remember to use the `linux-swap` partition type and include the swap mount on fstab for persistence (with mount-point `none` and fs `swap`)
- `vgcreate newvg /dev/sdb1 && lvcreate -l 50% -n newlv /dev/newvg && mkfs.xfs /dev/newvg/newlv`
  - Creating LVM logical volumes
  - Create a new vg `newvg` from `/dev/sdb1`, and;
  - Create a new lv `newlv` using 50% capacity (of extents) on vg `/dev/newvg`, and;
  - Format an XFS filesystem onto the mapped device at `/dev/newvg/newlv`
- `lvextend -r -L +1G /dev/newvg/newlv`
  - Extend `newlv` by 1G with the `-r` option to automatically extend the contained filesystem
- `wipefs -a /dev/sdb`
  - Wipe filesystem, including partition table, from block device `/dev/sdb`
- `stratis pool create mypool /dev/sdc && stratis pool list && stratis blockdev list && stratis fs create mypool myfs`
  - Create stratis pool `mypool` using device `/dev/sdc`, and;
  - List stratis pool
  - List stratis block devices
  - Create new stratis filesystem `myfs` on `mypool`
  - NOTE: Do not use `df -h` to measure pool size
- `cat >> ~/.bashrc <<EOF alias l='ls -laht' \n export EDITOR=vim \n EOF`
  - Read STDIN until EOF and add to file bashrc
- `systemctl show sshd` and `systemctl edit sshd.service` and `systemctl cat sshd`
  - View systemctl configurable parameters, and;
  - Edit systemctl service, always use this! Even for new services
    - For new services use `systemctl edit --force --full unit.type`
  - List out all unit files (`systemctl cat`)
- `dd if=/dev/sr0 of=/rhel9.iso bs=1M status=progress`
  - Stream input from `/dev/sr0` to output `/rhel9.iso` in block sizes of `1M` and show progress
- `mount -o remount,rw /`
  - Remount the root file system with RW privileges in emergency.target
  - NOTE: You may also want to use `mount -a` in emergency.target to mount all
- `init=/bin/bash && mount -o remount,rw / && passwd && touch /.autorelabel`
  - Process for changing root password from Grub prompt into shell drop
- `echo $?`
  - Get exit code of last command
- Vim
- `:w !sudo tee %`
  - Change to sudo vim without losing data
