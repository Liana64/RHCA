# Linux environment variables

A list of useful Linux environment variables.

**Commands**
```sh
env                          # Print current environment
export variable="value"      # Set an environment variable
```

**Environment variables**
```sh
$?                           # Last command exit code
$EDITOR                      # Default editor
$PATH                        # Path for binaries
$LANG                        # Language
$HISTSIZE                    # Size of history file
$USER                        # Current user
$HOME                        # Current user home dir
$TERM                        # Terminal capabilities (I think)
```
