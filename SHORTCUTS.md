# Linux Shortcuts

A list of useful Linux shortcuts.

**Basic Shortcuts**
```sh
Ctrl-L                    # Clear terminal
Ctrl-D                    # Delete character or exit terminal
Ctrl-A                    # Go to beginning of line
Ctrl-K                    # Delete line from cursor
Ctrl-S                    # Freeze terminal
Ctrl-Q                    # Unfreeze terminal
Ctrl-Z                    # Suspend to foreground (jobs)
Ctrl _                    # Undo

Tab                       # Autocomplete
Tab Tab                   # Show all matches

touch file-{0..100}       # Use parantheses #1
mv file.{txt,md}          # Use parantheses #2
```

**Advanced Shortcuts**
```
Alt .                     # Insert last used argument
\binary                   # Resolve command without aliases
reset                     # Fully reset terminal

!ech                      # Execute most recent command that starts with ech

systemctl status podmn    # Repeat last command with string replacement
^podmn^podman

Esc *                     # Insert all tab matches to STDIN
```
