### Logging and collection

**Setup persistent journal logs**
```sh
ls /run/log/journal                     # View persistent journal logs

echo "Storage=persistent" \             # Enable persisent journal logs
>> /etc/systemd/journald.conf

mkdir -p /var/log/journal \             # Make directory for persisent logs
chown :systemd-journal /var/log/journal # Owning group must be systemd-journal
```

**Using systemd-journald**
```sh
journalctl -u unit -p err               # Show errors only

journalctl -u unit \                    # Show logs by timestamp
--since "2025-01-01 10:00:00" \
--until "2025-01-01 12:00:00"

journalctl -ef <unit>                   # Tail journal logs
journalctl -xeu <unit>                  # Show logs starting at end

journalctl -xb                          # Show logs from last boot

journalctl -t setroubleshoot            # Troubleshoot SELinux
```

**Configure rsyslog**
```sh
echo "*.* @@remote:514" \               # Log all to remote over 514/tcp ("@@")
>> /etc/rsyslog.conf

echo "*.* @remote:514 " \               # Log all to remote over 514/udp ("@")
>> /etc/rsyslog.conf

systemctl restart rsyslog               # Restart service

firewall-cmd --permanent \              # Allow 514/tcp in the firewall
--add-port 514/tcp

firewall-cmd --permament \              # Allow 514/udp in the firewall
--add-port 514/udp

firewall-cmd --reload                   # Reload firewall to enable changes

firewall-cmd --list-all                 # List all firewall rules to verify
```

**Using auditd**
```sh
auditctl -a always,exit \               # Make auditd rule (memory)
-F arch=b64 \                           # On x64 architecture
-F path=/etc/passwd \                   # To monitor passwd file
-F perm=wa                              # When permissions change

auditctl -a always,exit \               # Make auditd rule (memory)
-F arch=b64 \                           # On x64 architecture
-F dir=/etc/sysconfig \                 # To monitor sysconfig directory
-S openat                               # For openat system call

auditctl -l                             # List all auditctl rules in memory

auditctl -l \                           # Save rules to memory
>> /etc/audit/rules.d/audit.rules       

ausearch -i -a 128                      # Search audit log for event ID 128
date -d @<epoch_timestamp>              # Translate epoch timestamp
```

### Systemd

**Systemd Dependency Types**

- `Requires=` starts the specified unit(s) when started
- `RequiresOverridable=` allows the required unit(s) to fail if run by an administrator
- `Requisite=` requires that the specified unit(s) are already running or will fail
- `Wants=` requests that the specified unit(s) are already running, but will not fail
- `Conflicts=` will stop all specified units if run
- `Before=` specifies that it will be loaded before the specified unit(s)
- `After=` specifies that it will be loaded after the specified unit(s)

**Using systemd**
```sh
systemctl set-default multi-user.target # Set default of multi-user.target

systemd-analyze blame                   # View slow units
systemd-analyze critical-chain          # View longest dependency path

systemctl --failed                      # View failed units
```

### Boot sequence

**Changing GRUB2 configuration**
```sh
ls -l /boot/loader/entries/*.conf       # View bootloader entries

grubby --args="rd.shell" \              # Add args to all kernels
--update-kernel=ALL                     # Drops shell on initramfs failure

grubby --remove-args="rhgb quiet" \     # Remove args from specific kernel
--update-kernel /boot/vmlinuz-[Tab]

# Old methodology that has been superceded by grubby and bootloader entries
vim /etc/default/grub                   # Edit grub defaults
cat /boot/grub2/grub.cfg                # View GRUB2 config (BIOS)
cat /boot/efi/EFI/redhat/grub.cfg       # View GRUB2 config (UEFI)

grub2-mkconfig -o /boot/grub2/grub.cfg  # Generate GRUB2 config (BIOS)

grub2-mkconfig \                        # Generate GRUB2 config (UEFI)
-o /boot/efi/EFI/redhat/grub.cfg

dnf reinstall grub2-efi-x64 shim-x64    # Install signed image
yum reinstall grub2-efi shim            # Another method
```

**Boot from grub menu**

1. Press "e" to edit
2. Navigate to "linux"
3. Add one of the following:
    - `rd.break` (Break before root is mounted)
    - `systemd.unit=rescue.target` (Single user with local FS mounted)
    - `systemd.unit=emergency.target` (Minimal with root FS mounted read only)
    - `init=/bin/bash` (Bypass systemd)
4. Press Ctrl+X to boot
5. If no root (`rd.break`), use:
    - `mount -o remount,rw /sysroot`
    - `chroot /sysroot`
6. To remount root with write perms, use:
    - `mount -o remount,rw /`
8. Change root password using `passwd` if desired
9. To trigger relabeling on next boot:
    - `touch /.autorelabel`, or:
    - `restorecon -v /somefile`
10. To start systemd manually:
    - `exec /usr/lib/systemd/systemd`
    - or, `exit`

**Boot from grub prompt**
```sh
normal                                  # Abort and return to grub menu

insmod xfs; insmod lvm; insmod ext4     # 1. Load fs kernel modules
ls && ls (hd0,gpt1)/                    # 2. List boot drive (need trailing "/")
set root=(lvm/fedora-root)              # 3. Set root directory

linux (hd0,gpt1)/vmlinuz-[Tab] \        # 4. Declare kernel
root=/dev/fedora/root

initrd (hd0,gpt1)/initramfs[Tab]        # 5. Load initramfs (ramdrive)
boot                                    # 6. Boot
grub2-mkconfig -o /boot/grub2/grub.cfg  # 7. Make persistent (optional)
```

```sh

```

**RPM Database recovery**
```sh
rpm -qa                                 # Shows few or no packages (symptom)

cp -a /var/lib/rpm \                    # Backup rpmdb
/var/lib/rpm.bak

rpm --rebuilddb                         # Rebuild rpmdb
restorecon -Rv /var/lib/rpm             # Restore SELinux perms \* CRITICAL
```

**Investigating RPMs**
```sh
rpm -qf /some/file                      # Show owning package of file
rpm -qR package                         # Show package dependencies
rpm -qp --scripts package.rpm           # Show scripts run by package

dnf provides '*/libssl.so*'             # Find which package provides a library
```
